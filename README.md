# deepritz
本项目旨在使用deepritz方法复现学术论文 "Branching of twins near an austenite—twinned-martensite interface" 中的核心模拟结果。/The objective of this project is to reproduce the key findings from the seminal paper, "Branching of twins near an austenite—twinned-martensite interface," by employing the Deep Ritz Method.
